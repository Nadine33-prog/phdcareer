田老师您好

压缩包是完整项目。您在自己电脑上按这个顺序做一遍就能打开页面，也能进后台改数据。我按Windows写的。哪一步卡住了微信跟我说。


一、开始之前

    1. 装Node.js
        去这个网址下载，选20以上的版本。
        https://nodejs.org
        装完打开命令提示符，打下面两句，能出版本号就行。
        node -v
        npm -v

    2. 装MySQL
        去这个网址下载8。
        https://dev.mysql.com/downloads/mysql/
        安装的时候会让你设一个root密码，后面要用，先记下来。

    3. 建数据库
        装好后建一个空数据库，名字就叫phd_career。用Workbench或者Navicat建都行。命令行的话先打
        mysql -u root -p
        进去之后再执行
        CREATE DATABASE phd_career DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
        这两个软件没装好，后面不用做了。


二、解压和配置

    1. 解压
        解压到一个好找的地方，比如D盘phd-career。

    2. 删掉node_modules
        如果里面有node_modules这个文件夹，删掉。那是我电脑上的，到您这边要重新装。

    3. 建配置文件
        打开项目里的server文件夹，新建一个记事本，把文件名改成.env  注意前面有个点，后面不要带txt。用记事本打开，把下面几行贴进去，把密码改成您自己的MySQL密码。

        DATABASE_URL=mysql://root:这里换成您的密码@localhost:3306/phd_career
        JWT_SECRET=beyond-academia-local
        PORT=3000
        CORS_ORIGIN=http://localhost:5173
        NODE_ENV=development

        密码里要是有特殊符号，连接可能会出问题，跟我说一声我帮您改。


三、安装和导入数据

    1. 打开终端
        在项目最外层那个文件夹打开终端。资源管理器上面地址栏打cmd回车就行，或者空白处Shift加右键，选在此处打开PowerShell。

    2. 按顺序执行
        一行跑完再跑下一行。
        npm install
        cd server
        npm install
        npx prisma migrate deploy
        npx prisma db seed

    3. 注意
        最后那条会把管理员账号写进去，还有现在这批示意的岗位和数据。只第一次装的时候跑。您以后在后台改过真数据，就不要再跑了，不然会覆盖掉。


四、启动和登录

    1. 启动
        如果终端还停在server里面，先打
        cd ..
        回到最外层，再打
        npm run dev
        正常会出现两个地址。前端是http://localhost:5173  接口是http://localhost:3000

    2. 看前台
        浏览器打开http://localhost:5173就能看。关掉这个黑窗口，网站就停了。下次还用，进这个文件夹再打一次npm run dev就行，不用重装，也不用再导数据。

    3. 进后台
        浏览器打开http://localhost:5173/admin
        用户名 admin
        密码 admin123
        进去可以改岗位、薪资、去向、访谈，评估用的权重和职位预警规则也能改。前面那些页面不用登录就能看。


五、真实数据怎么补

    现在库里的是示意数据，先把页面走通。真数据有两种办法，您看着方便用哪种。

    1. 直接在后台改
        岗位、职业数据里面增删改，改完刷新前台就能看到。这个省事。

    2. 填表发我
        项目里有个data\collect文件夹，几张表用Excel打开就行，旁边有采集说明。您按那个填好发我，我帮您导进去。

    3. 决策工具简单说两句
        门槛评估现在的百分位是按我们定的标准估算的，等以后大概有200个人在网上填过，可以改成跟真实填表的人对比。职业匹配和职位预警用的是比较直接的匹配，怎么对、抓哪些词，您都可以在后台权重矩阵和风险规则里自己加、自己改。


六、常见问题

    1. 打npm提示不是内部或外部命令
        就是Node没装好，或者装完没关终端重开。重装一下，关掉窗口再开一次。

    2. 连不上数据库
        多半是.env里密码不对，或者MySQL没开，或者库名不是phd_career。

    3. 页面能开但是岗位是空的，或者评估报错
        多半是接口没起来。看黑窗口里有没有学术之外API已启动这句，没有就把报错截给我。

    4. 提示端口被占用
        把以前开过的窗口关掉再启动一次。

    5. 想全部重来
        把库删了再建一个空的phd_career，再跑一遍migrate deploy和db seed。这样后台改过的东西会没。
