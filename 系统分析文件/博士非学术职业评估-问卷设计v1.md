# 博士非学术职业评估 · 问卷结构化设计 v1.0

供「学术之外 / Beyond Academia」系统开发用。
设计参照：myIDP（AAAS/Science Careers，面向 STEM 博士，20 条职业路径）与 ImaginePhD（Graduate Career Consortium，面向人文社科博士，16 个 Job Families）。

---

## 0. 设计原则（从参照工具提炼）

1. **兴趣 + 技能入匹配算法；价值观不入算法**。价值观仅做强制排序（Top 5），并为结果页生成个性化"追问清单"——两个国际工具的共同成熟设计，避免普遍性偏好（钱多、稳定）污染匹配区分度。
2. **题项写"任务/活动"，不写"身份"**。问"我喜欢把研究发现写成面向决策者的短报告"，不问"我适合去智库吗"。
3. **专家权重矩阵**是匹配骨架：每个职业方向 × 每个题项，由专家预先评定"该方向对此项的要求/相关度"（0-3）。v1 由编辑部预填跑通算法，上线后参照 ImaginePhD 的做法（约 30 位专家、任职 5 年以上）做正式调查替换。
4. **强制使用全区间**：作答页提示"请使用 1-5 的完整范围"；若某模块全部题目评分相同，弹出提醒（参照 myIDP 的 anti-顶格 机制）。
5. **中国情境模块（E）为本土新增**：编制、地域、薪资底线、纪律性组织接受度。**不参与排序**，仅在结果页生成冲突提示标签（保持"探索起点而非决策终点"的产品定位）。

## 2. 数据结构定义（开发用）

### 2.1 题项表 items

| 字段 | 类型 | 说明 |
|---|---|---|
| item_id | varchar(4) | 如 B07、C12、D03、E01 |
| module | enum | A/B/C/D/E |
| dimension | varchar | B 题为主要方向代码；C 题为技能域代码 |
| text_zh | text | 中文题干 |
| scale_type | enum | likert5 / single_choice / rank_select |
| reverse | bool | 是否反向计分（v1 全部 false，预留） |
| version | int | 题库版本号 |

### 2.2 权重矩阵表 weights（B、C 模块题目 × 9 方向）

| 字段 | 类型 | 说明 |
|---|---|---|
| item_id | varchar(4) | 关联 items |
| direction_id | int (1-9) | 1教育教研 2科研院所 3学术支撑 4社会智库 5党政管理 6军警文职 7企业研究 8文化与出版 9医疗卫生 |
| weight | int (0-3) | 0 无关 / 1 略相关 / 2 相关 / 3 核心要求 |
| source | enum | editorial（编辑部预填）/ expert_survey（专家调查） |

### 2.3 匹配算法（v1）

```
用户兴趣向量 I[36]，技能向量 S[24]（原始 1-5）

第一步 个体内中心化（抵消打分风格）：
  I'[i] = I[i] - mean(I);  S'[i] = S[i] - mean(S)

第二步 分方向加权得分：
  interest_score(d) = Σ_i ( I'[i] × W_I[d][i] ) / Σ_i W_I[d][i]
  skill_score(d)    = Σ_i ( S'[i] × W_S[d][i] ) / Σ_i W_S[d][i]

第三步 合成并归一化到 0-100：
  raw(d) = 0.5 × interest_score(d) + 0.5 × skill_score(d)
  match%(d) = minmax_normalize(raw, across 9 directions) × 100

第四步 排序输出；并按 E 模块规则附加提示标签（见 §7）
```

雷达图五维（结果页展示用，与门槛评估工具视觉统一）：
研究倾向 / 表达传播 / 组织协调 / 技术数据 / 服务育人
（由 C 模块 6 技能域折算：C-1→研究，C-2→表达，C-3+C-4→组织，C-5→技术，C-6→服务；兴趣分不进雷达图。）

## 6. 模块 D · 价值观（18 项，拖拽选出 Top 5 并排序）

作答页提示：**"从下列 18 项中选出对你最重要的 5 项并排序。系统限制最多 5 项——被迫取舍正是本环节的意义。"**

价值观**不参与匹配排序**。结果页按用户 Top 5 输出"选择任何岗位前你应当追问的问题"（参照 myIDP：针对最强价值观生成岗位评估问题清单）。

| ID | 价值项 | 结果页追问模板（示例） |
|---|---|---|
| D01 | 工作稳定性与保障（编制/长期合同） | 这个岗位的编制性质是什么？续聘/裁撤的历史记录如何？ |
| D02 | 高收入与物质回报 | 该岗位近三年实际到手收入的中位数是多少（而非 offer 区间上限）？ |
| D03 | 学术自由与研究自主权 | 选题自由度多大？成果归属如何界定？ |
| D04 | 社会地位与职业声望 | 这个头衔在你在意的圈子里如何被看待？ |
| D05 | 工作生活平衡 | 在岗者如何描述典型的一周？加班是常态还是例外？ |
| D06 | 帮助他人 / 社会公益 | 你的工作成果最终惠及谁？链条有多长？ |
| D07 | 智力挑战与持续学习 | 入职三年后，这个岗位还能让你学到新东西吗？ |
| D08 | 创造与创新空间 | 提出新想法在这里会被鼓励还是被视为麻烦？ |
| D09 | 明确的晋升通道 | 从该岗位到上一级平均需要几年？卡点在哪里？ |
| D10 | 团队归属感与同事关系 | 团队流动率如何？离开的人为什么离开？ |
| D11 | 独立自主的工作方式 | 日常工作受多少层审批约束？ |
| D12 | 对公共政策/社会的影响力 | 你的报告/成果真的会被决策者读到吗？ |
| D13 | 地理位置的自由度 | 该岗位是否绑定特定城市？调动可能性多大？ |
| D14 | 职业转换的灵活性 | 从这个岗位跳出去，市场认可哪些经验？ |
| D15 | 权力与决策参与 | 多少年资后你能参与真正的决策？ |
| D16 | 工作内容的多样性 | 一年后你的工作内容会有多大比例是重复的？ |
| D17 | 规则明确、边界清晰的职责 | 岗位职责说明书与实际工作的一致性如何？ |
| D18 | 与家庭责任的兼容性 | 请假、育儿、照护在这个单位的实际容忍度？ |

### 冲突提示规则（v1）

| 用户选择 | 触发标签的方向 | 提示文案模板 |
|---|---|---|
| E01=必须有编制 | 企业研究 | 该方向以市场化聘用为主，与你的编制偏好存在冲突 |

## 9. 结果页信息架构

1. **头部**：Top 1 方向大字 + 匹配百分比 + 一句话画像
2. **9 方向匹配条形排序**（含 E 模块冲突角标）
3. **五维雷达图**（研究 / 表达 / 组织 / 技术 / 服务）
4. **Top 3 方向卡片**：方向简介 + 代表岗位 + 「查看职业地图详情」跳转（复用现有 FamilyDetailPage）
5. **价值观追问清单**：按用户 Top 5 价值生成 5-10 条"面试/调研时应当问的问题"
6. **免责声明**（与门槛评估工具同款语气）：本评估反映的是兴趣与技能的相对倾向，仅作为职业探索的起点，不构成对任何具体决策的建议。

## 10. 与现有原型的衔接备忘

- 现原型 PersonalityPage 文案为"24 道情境题，约 8 分钟"，实施本设计后应改为"约 87 道快速自评题，约 8 分钟"；
- 现原型雷达图六维（学术倾向/结构化/跨界整合/执行力/影响力/稳定性偏好）替换为本设计五维；
- 结果类型名（如"跨界整合者"）可保留为 Top 1 方向的画像标签体系，需另行设计 9 方向 × 画像文案。
