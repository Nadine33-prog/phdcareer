# 博士职业数据采集说明

---

## 一、规则

1. 一行 = 一条独立记录。没有原文链接的岗位/薪资/占比，请不要填。
2. 本项目面向**中国博士**的职业探索，只针对和博士就业相关的数据。
4. **时间范围：** 岗位优先收**正在招聘或近 12 个月**的公告；薪资、去向占比优先 **2021–2026 年**。
5. **地域范围：** 以中国大陆为主。国际组织岗位可以收驻华机构或面向中国博士的空缺。
6. **`01-岗位.csv`、`02-薪资.csv` 里已有一行示例，交回前请删掉。**
7. **分类编号只能填 1–8**，必须和「分类名」对得上。对照见下一节。

## 三、`01-岗位.csv`

**一行 = 一条岗位。** 目标：总共约 80 条，**8 个分类每类至少 6 条**。

### 查找范围

- 各高校人事处 / 人才招聘网
- 中国博士后网、科学网人才、高校人才网
- 中科院、社科院、国研中心官网人事栏
- 国家公务员局、各省选调生公告
- 军队人才网、事业单位公开招聘
- 企业**官网**招聘页（博士 / 研究员 / 研究部）
- UN Careers、UNESCO Careers

### 填写规则

| 列名 | 必填 | 取值范围 / 填法 | 正确例子 | 不要这样填 |
|---|---|---|---|---|
| 岗位名称 | 是 | 公告上的职位名，尽量原样抄，3–30 字 | 青年研究员（特聘） | 「高校老师」 |
| 单位 | 是 | **具体用人单位全称或常用规范简称**，不要只写「某高校」「互联网大厂」。范围见上一节「优先找的单位」 | 复旦大学新闻学院；字节跳动；上海市委组织部 | 某 985；某券商；BAT |
| 地区 | 是 | `北京` `上海` `广深` `江浙` `海外`。不在这 5 个里，直接写城市名，如 `长沙` `成都` `武汉` | 上海；广深；长沙 | 华东；全国；remote（可写「远程」，不要写英文乱码） |
| 类型 | 是 | **填下面 6 个之一：** `学术` `智库/研究院` `产业研究` `出版传媒` `体制内` `国际组织` | 学术 | 高校；企业；R&D；事业编 |
| 分类编号 | 是 | 只能 `1`–`8`，见第二节 | 1 | 01；学术支撑；9 |
| 薪资 | 能抄就抄 | 按公告原文抄。可以是区间。面议就写 `面议`。单位尽量带「万」以免和月薪混淆 | 25-35 万；80-180 万；面议 | 很高；待遇从优（除非原文只有这四字，可抄原文并在备注说明） |
| 发布日期 | 是 | `YYYY-MM-DD`。以公告落款或页面日期为准 | 2025-11-02 | 3 天前；今天；2025年11月 |
| 岗位职责 | 是 | 从原文摘 **3–6 条**，条与条之间用英文竖线 `\|` 分隔，不要整段粘贴 2000 字 | 承担本科课程\|申报国家级课题\|发表 SSCI 论文 | 一整段不换行的公告全文 |
| 任职要求 | 是 | 必须能看出博士门槛。硬条件（学历、年龄、论文、党员、英语）优先。同样用 `\|` 分隔 | 博士学位\|35周岁以下\|SSCI一作≥3篇 | 「优秀者可放宽」单独一条可以保留，但不要只有这一条 |
| 福利待遇 | 有就填 | 编制、住房、启动经费、股票等。用 `\|` 分隔 | 预聘3+3\|周转房\|年薪25-35万 | 空白也行；不要编「五险一金」如果原文没写 |
| 出处名称 | 是 | 哪一份公告，写人能看懂的名字 | 复旦大学 2025 年专任教师招聘公告 | 网上；百度；师兄说的 |
| 原文链接 | 是 | 以 `http://` 或 `https://` 开头，点开必须是该公告或官方招聘页 | https://hr.xxx.edu.cn/info/1234.htm | 没有链接；www.baidu.com；微信截图 |
| 备注 | 否 | 给编辑看的话，如前「预聘制」「即将截止」 | 典型预聘制，考核条款在公告第 4 条 | 不要写情绪评价 |

## 四、`02-薪资.csv`

**一行 = 某一个机构、某一个职位、某一年的一个年薪数字。** 目标：约 40 条，**每个分类至少 3 条**。

数字必须来自公告、官方工资标准或具名公开报告，**单位：万元/年，税前**。

### 去哪找

- 高校/院所公开聘任公告里写明的年薪
- 公务员、事业编制、选调工资标准
- 军队文职公告中的待遇表述
- UN / UNESCO 公开薪级表
- 猎聘、智联、麦克思等**公开发布的年度薪酬白皮书**（只引用报告结论，注明报告名和年份）

### 每一列怎么填

| 列名 | 必填 | 取值范围 / 填法 | 正确例子 | 不要这样填 |
|---|---|---|---|---|
| 机构 | 是 | 具体单位。如果是报告里的汇总，必须写清口径 | 复旦大学；C9高校（就业报告平均） | 某大学；互联网 |
| 职位 | 是 | 和材料里的职位名一致 | 青年研究员（特聘）；定向选调生 | 老师；高薪岗 |
| 分类名 | 是 | 只能是第二节 8 个中文名，一字不差 | 学术支撑 | 高校；科技；1 |
| 分类编号 | 是 | 1–8，且必须和分类名匹配 | 1 | 4（却写学术支撑） |
| 年薪万元 | 是 | **正整数，不要写「万」、不要写区间。** 公告是 25–35 万时，填中值 `30`，并在来源名称里写「公告区间25-35万，取中值」 | 28 | 28万；25-35；280000 |
| 年份 | 是 | 四位数字，优先 2021–2026 | 2026 | 25；2025届 |
| 样本数 | 是 | 该数字背后有多少人。公告只给一个岗、人数不明，填 `1`。报告写了 n=86 才能填 86 | 1 | 乱编 122 |
| 来源名称 | 是 | 材料全名 | 复旦大学 2025 年公开聘任公告；猎聘《2025 高校毕业生薪酬报告》 | Offer 聚合；听说 |
| 原文链接 | 尽量必填 | 能打开的公告或报告页。没有链接的汇总行，来源名称必须写到报告名，链接可空 | https://... | 随便挂一个官网首页充数（可以，但最好挂到具体公告） |
| 城市 | 否 | 各地工资不同时再写 | 上海 | 全国（除非报告口径就是全国） |

### 按分类，优先抄什么数字

| 分类 | 优先抄 | 常见出处 |
|---|---|---|
| 1 学术支撑 | 预聘 / 青年研究员年薪 | 高校人事处公告 |
| 2 党政管理 | 选调或公务员工资区间（取中值填年薪万元） | 各地工资标准、选调简章 |
| 3 社会智库 | 事业编或协议年薪 | 院所招聘公告 |
| 4 科技企业 | 报告中的「博士 × 该职位」区间中值；官网写了年包也可抄 | 薪酬白皮书、企业招聘页 |
| 5 文化出版 | 事业编编辑 / 馆员 | 出版社、图博公告 |
| 6 医疗健康 | 医院科研岗、药企科学家 | 医院公示、药企官网 |
| 7 军警文职 | 文职待遇（折算年薪） | 军队人才网 |
| 8 其他 | UN P2/P3 年薪（注意币种，折人民币需在来源名称注明汇率和年份） | UN 公开薪级表 |

## 五、`03-去向占比.csv`

**一行 = 某一所学校（或全国口径）+ 某一个毕业年 + 博士层次的去向结构。**  
这不是「某个人去了哪」，而是报告里的**百分比**。

目标：至少 10 所高校 × 2021–2025**（能找到几年写几年）。

### 学校或口径：应该找哪些学校

**第一优先（尽量找全）**

北京大学、清华大学、复旦大学、上海交通大学、浙江大学、南京大学、中国科学技术大学、哈尔滨工业大学、西安交通大学

**第二优先：** 学科代表性 985，例如中国人民大学、北京师范大学、武汉大学、中山大学、厦门大学、同济大学、东南大学、四川大学、中南大学、南开大学、天津大学

**也可以收：** 教育部或研究生质量报告里的「全国博士」汇总行，此时「学校或口径」写成 `教育部全国` 或报告里的原口径全称。

**不要收：** 只有本科或硕士拆分、没有博士专章的数据；国外大学本科就业报告；知乎上的个人估计。

### 去哪找

在学校官网、就业指导中心、信息公开栏搜索：`学校名 + 毕业生就业质量年度报告`，下载 PDF。只抄**博士**章节。

### 学术 / 企业 / 机关 / 其他是不是百分比？

**是，填 0–100 的数字，不要加 `%` 号。** 四个占比相加应约等于 100（允许四舍五入差 1–2 个百分点）。

四个口径请尽量按报告原文归并：

| 列名 | 把报告里的哪些去向算进来 |
|---|---|
| 学术占比 | 高等学校、科研院所、博士后（若报告把博后单列，请在页码旁备注，并尽量归入学术） |
| 企业占比 | 国有企业、民营企业、三资企业、医疗机构里的企业编制等 |
| 机关占比 | 党政机关、事业单位（若报告把「高等教育单位」已单独算进学术，就不要再算进机关） |
| 其他占比 | 部队、国际组织、自主创业、灵活就业、待就业等其余部分 |

如果某校报告只有「深造 / 就业」两栏、**没有博士去向行业拆分**，这一年不要硬填，换一所学校或换一年。

### 每一列怎么填

| 列名 | 必填 | 取值范围 / 填法 | 正确例子 | 不要这样填 |
|---|---|---|---|---|
| 学校或口径 | 是 | 学校全称，或 `教育部全国` | 北京大学 | 北大；某 985 |
| 年份 | 是 | 四位毕业年，优先 2021–2025 | 2024 | 2024届；24 |
| 学位层次 | 是 | 本表只允许填 `博士` | 博士 | 本科；研究生（含硕博混合） |
| 学术占比 | 能抄就抄 | 0–100 的数字，不要写 % | 41 | 41%；大约四成 |
| 企业占比 | 能抄就抄 | 同上 | 29 | |
| 机关占比 | 能抄就抄 | 同上 | 18 | |
| 其他占比 | 能抄就抄 | 同上；四项相加约 100 | 12 | 把未知部分随便塞进其他且不注明 |
| 博士人数 | 有就填 | 该年博士就业（或毕业）人数，正整数 | 860 | 编一个人数 |
| 来源名称 | 是 | 报告封面全名 | 北京大学 2024 年毕业生就业质量年度报告 | 学校官网 |
| 原文链接 | 是 | PDF 或官方发布页 | https://xxx.edu.cn/xxx.pdf | 没有链接 |
| 页码 | 否 | 方便复核 | 17 | |
